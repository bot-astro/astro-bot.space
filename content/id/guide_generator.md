## Apa itu generator?

Generators are channels created and managed by Astro.  
When a user joins a generator, Astro creates a temporary voice channel and moves the user in it.

The user that creates the temporary voice channel it's called owner.
The owner can manage the channel with the Astro slash commands or with the [interfaces](/guides/interface), both allow the user to change the channel name, user limit, permissions and everything else.

Once the owner leaves, if there are other _non-bots_ users in the channel, the ownership will be transferred randomly to another user.  
When instead the owner leaves and there are no more users in the channel, it will get deleted.

Generator sangat dapat disesuaikan, di panduan ini kamu akan belajar mengonfigurasinya agar sesuai persis dengan kebutuhan servermu!

## Membuat dan mengelola generator

Astro can manage multiple generator and each has its own settings.  
On the generators section of the dashboard you will be able to see all the generators of your server, create new ones, manage and delete them.

_Ingat bahwa tanpa [Ultimate](/ultimate) kamu hanya bisa memiliki maksimal 2 generator._

## Pengaturan nama

A temporary voice channel can be in three different states: default, locked or hidden.  
These states are toggled by users either via slash commands or the interface.

Kamu bisa memberi nama untuk setiap status:
![pengaturan nama generator](/guides/generator_name.png "Pengaturan nama generator")

### Variabel

You can make use of `Variables` to make the channel name dynamic. Astro will replace the variables with the appropriate value when applying the new name:

#### Variabel pemilik saluran suara

| Variabel     | Deskripsi                                             |
| ------------ | ----------------------------------------------------- |
| `{nickname}` | Nama panggilan (atau username jika tidak ada) pemilik |
| `{username}` | Username pemilik                                      |
| `{mention}`  | Mention (@nama) pemilik                               |
| `{id}`       | ID pemilik                                            |

#### Variabel aktivitas pemilik saluran suara · [membutuhkan Ultimate](/ultimate)

| Variabel                | Deskripsi                                                   |
| ----------------------- | ----------------------------------------------------------- |
| `{activity_name}`       | Nama aktivitas pemilik (misalnya nama game)                 |
| `{activity_emoji}`      | Emoji yang mewakili aktivitas                               |
| `{activity_start_time}` | Waktu saat pemilik memulai aktivitas                        |
| `{activity_end_time}`   | Waktu saat aktivitas akan atau telah berakhir               |
| `{activity_type}`       | Jenis aktivitas (bermain, menonton, mendengarkan, dll.)     |
| `{activity_link}`       | Tautan siaran Twitch jika aktivitasnya adalah siaran Twitch |

#### Variabel saluran suara

| Variabel         | Deskripsi                                           |
| ---------------- | --------------------------------------------------- |
| `{vc_name}`      | Nama saluran suara                                  |
| `{vc_bitrate}`   | Bitrate saluran suara                               |
| `{vc_userlimit}` | Batas pengguna saluran suara                        |
| `{vc_users}`     | Jumlah pengguna di saluran suara                    |
| `{vc_id}`        | ID saluran suara                                    |
| `{vc_mention}`   | Saluran suara dalam bentuk mention (#saluran-suara) |

#### Variabel nilai bertahap · [membutuhkan Ultimate](/ultimate)

| Variabel  | Deskripsi                                        |
| --------- | ------------------------------------------------ |
| `{n}`     | Angka bertahap sederhana (1, 2, 3...)            |
| `{nato}`  | Alfabet NATO bertahap (Alpha, Bravo, Charlie...) |
| `{roman}` | Angka Romawi bertahap (I, II, III, IV...)        |

**Bagaimana cara kerja angka bertahap?**  
Mengingat batasan baru Discord yang hanya mengizinkan penggantian nama saluran suara 2 kali setiap 10 menit, fitur ini bekerja sedikit berbeda dari yang mungkin kamu harapkan:  
Saluran suara akan dibuat secara bertahap: bot akan mencari saluran suara pertama yang hilang dan menempatkan saluran suara baru di posisinya.

Example: We have 5 VCs generated by Astro incrementally [VC #1, VC#2, VC #3, VC #4 and VC#5], now let's say VC #3 gets deleted, what Astro will not do is rename every single VC to the proper name, so VC#4 to VC #3 and so on, instead the next time a VC will be created it will not be VC #6 but VC #3 so that the gap gets filled.

Jika kamu melihat angkanya dimulai dari angka yang salah, kamu bisa menekan tombol `Hapus cache` di dashboard untuk mengatur ulang hitungan
![hapus cache](/guides/clear_cache.png "Hapus cache")

### Kondisi pembaruan nama

Kamu juga bisa mengatur kapan nama saluran harus diperbarui:
![kondisi pembaruan nama generator](/guides/generator_name_conditions.png "Kondisi pembaruan nama generator")

### Batasan pembaruan nama

The name of a Discord voice channel can be changed only 2 times per every 10 minutes, Discord introduced this limitation a while ago, unfortunately.
Because of that voice channel names may not be always precise if frequent changes occur.

## Pengaturan dasar

Di dashboard kamu juga akan menemukan opsi untuk mengubah:

- kategori tempat saluran suara sementara dibuat
- batas pengguna
- bitrate
- posisi: apakah saluran suara sementara dibuat tepat sebelum generator, tepat setelahnya, atau di bagian bawah kategori
- untuk mengubah wilayah, kamu bisa mengubah wilayah saluran generator langsung di dalam Discord
- status default saluran suara: teks kecil yang ditampilkan di bawah nama saluran suara, pemilik dapat mengubahnya kapan saja dengan perintah `/status`

## Pengaturan izin

### Pewarisan izin

Temporary voice channels by default inherit the permissions from the generator.  
You can change this behaviour on the dashboard, you can make channels copy the permissions from the category instead or not copy any permission at all.

### Peran target

The target role is one of the most important settings. When the channel permissions need to be modified, for example when it gets locked or hidden, Astro will modify the permissions of the target role to achieve the desired state.  
As an example, if in your server users must complete a verification process and get a `Verified` role, then you probably wanna set that as the target role.

### Peran moderator

Jika kamu menentukan peran moderator, peran itu akan selalu memiliki izin yang diperlukan untuk mengelola saluran, bahkan saat saluran dikunci atau disembunyikan.

### Status default

Kamu bisa menentukan apakah saluran suara sementara dibuat dalam keadaan terkunci atau tersembunyi secara default.

## Pengaturan perintah

Kamu bisa memberi beberapa batasan pada perintah pengguna, seperti apakah mereka boleh menggunakan kata kasar pada nama saluran suara mereka (hanya berfungsi dalam bahasa Inggris), serta menentukan nilai minimum dan maksimum yang dapat digunakan pengguna untuk batas pengguna dan bitrate.

## Utilitas

### Peran pemilik

Jika ditentukan, Astro akan memberikan peran ini kepada pemilik saluran suara sementara, dan mencabutnya saat mereka meninggalkan saluran atau saat kepemilikan dipindahkan.

### Mode antrean

With queue mode enabled, Astro will try to fill existing channels before creating new ones.  
Useful feature when channels have a user limit set and you need to make sure that channels are all filled with the maximum amount of users.

### Generator cadangan

Saat kategori generator penuh (mencapai 50 saluran), pengguna yang bergabung ke generator akan dipindahkan ke generator cadangan jika sudah diatur.

## Ruang tunggu

A waiting room is simply a voice channel that gets created near a temporary voice channel.  
Users can join the waiting room to indicate that they are waiting to get in the temporary voice channel, and the owner of it can drag users from the waiting room to its channel.

Di dashboard kamu dapat memilih apakah Astro harus otomatis membuat ruang tunggu untuk setiap saluran suara sementara dan mengonfigurasi semua aspeknya: nama (variabel juga bisa digunakan di sini), batas pengguna, bitrate, dll.

Pengguna juga dapat membuat ruang tunggu dengan perintah slash atau tombol interface yang sesuai.

## Obrolan teks pribadi

A private text chat instead is a text channel that is only visible to users inside a temporary voice channel.  
You can configure whether Astro should create a private text chat for each temporary voice channel on the dashboard, along with its settings, like for waiting rooms.

Pengguna juga dapat membuat obrolan teks pribadi dengan perintah slash atau tombol interface yang sesuai.

### Pesan pembuatan

You can also provide a message that Astro sends into temporary voice channels when created.  
The message will be sent in the private text chat if that exists, otherwise in the voice channel chat (yeah it's confusing, but voice channels now also have an integrated text chat).

Kamu bisa memilih apakah pesan berupa embed atau pesan teks biasa.

Atau, kamu bisa membuat Astro mengirim [interface](/guides/interface) di obrolan teks!
