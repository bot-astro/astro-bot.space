## Generator คืออะไร?

Generator คือช่องที่ Astro สร้างและจัดการ  
เมื่อผู้ใช้เข้า Generator Astro จะสร้างช่องเสียงชั่วคราวและย้ายผู้ใช้เข้าไป

ผู้ใช้ที่สร้างช่องเสียงชั่วคราวเรียกว่าเจ้าของ
เจ้าของจัดการช่องได้ด้วยคำสั่งสแลชของ Astro หรือด้วย[อินเทอร์เฟซ](/guides/interface) ซึ่งทั้งสองอย่างช่วยให้เปลี่ยนชื่อช่อง ขีดจำกัดผู้ใช้ สิทธิ์ และอื่นๆ ได้ทั้งหมด

เมื่อเจ้าของออกไป หากยังมีผู้ใช้ที่ _ไม่ใช่บอท_ อยู่ในช่อง ความเป็นเจ้าของจะถูกโอนให้ผู้ใช้คนอื่นแบบสุ่ม  
แต่ถ้าเจ้าของออกไปและไม่มีผู้ใช้เหลืออยู่ในช่องแล้ว ช่องจะถูกลบ

Generator ปรับแต่งได้สูงมาก ในคู่มือนี้คุณจะได้เรียนรู้วิธีตั้งค่าให้เหมาะกับความต้องการของเซิร์ฟเวอร์คุณพอดี!

## สร้างและจัดการ Generator

Astro จัดการ Generator ได้หลายตัว และแต่ละตัวมีการตั้งค่าของตัวเอง  
ในส่วน Generator ของแดชบอร์ด คุณจะเห็น Generator ทั้งหมดของเซิร์ฟเวอร์ สร้างตัวใหม่ จัดการ และลบได้

_อย่าลืมว่าหากไม่มี [Ultimate](/ultimate) คุณมี Generator ได้สูงสุด 2 ตัว_

## การตั้งค่าชื่อ

ช่องเสียงชั่วคราวอยู่ได้ใน 3 สถานะ: ค่าเริ่มต้น ล็อก หรือซ่อน  
ผู้ใช้สลับสถานะเหล่านี้ผ่านคำสั่งสแลชหรืออินเทอร์เฟซ

คุณตั้งชื่อให้แต่ละสถานะได้:
![การตั้งค่าชื่อของ Generator](/guides/generator_name.png 'การตั้งค่าชื่อของ Generator')

### ตัวแปร

คุณใช้ `ตัวแปร` เพื่อทำให้ชื่อช่องเปลี่ยนแปลงได้ Astro จะแทนที่ตัวแปรด้วยค่าที่เหมาะสมเมื่อใช้ชื่อใหม่:

#### ตัวแปรของเจ้าของช่องเสียง

| ตัวแปร       | คำอธิบาย                                     |
| ------------ | -------------------------------------------- |
| `{nickname}` | ชื่อเล่น (หรือชื่อผู้ใช้หากไม่มี) ของเจ้าของ |
| `{username}` | ชื่อผู้ใช้ของเจ้าของ                         |
| `{mention}`  | การกล่าวถึง (@ชื่อ) ของเจ้าของ               |
| `{id}`       | ID ของเจ้าของ                                |

#### ตัวแปรกิจกรรมของเจ้าของช่องเสียง · [ต้องใช้ Ultimate](/ultimate)

| ตัวแปร                  | คำอธิบาย                                     |
| ----------------------- | -------------------------------------------- |
| `{activity_name}`       | ชื่อกิจกรรมของเจ้าของ (เช่น ชื่อเกม)         |
| `{activity_emoji}`      | อีโมจิที่แทนกิจกรรม                          |
| `{activity_start_time}` | เวลาที่เจ้าของเริ่มกิจกรรม                   |
| `{activity_end_time}`   | เวลาที่กิจกรรมจะสิ้นสุดหรือสิ้นสุดแล้ว       |
| `{activity_type}`       | ประเภทของกิจกรรม (เล่น ดู ฟัง ฯลฯ)           |
| `{activity_link}`       | ลิงก์สตรีม Twitch หากกิจกรรมเป็นสตรีม Twitch |

#### ตัวแปรของช่องเสียง

| ตัวแปร           | คำอธิบาย                                  |
| ---------------- | ----------------------------------------- |
| `{vc_name}`      | ชื่อของช่องเสียง                          |
| `{vc_bitrate}`   | บิตเรตของช่องเสียง                        |
| `{vc_userlimit}` | ขีดจำกัดผู้ใช้ของช่องเสียง                |
| `{vc_users}`     | จำนวนผู้ใช้ในช่องเสียง                    |
| `{vc_id}`        | ID ของช่องเสียง                           |
| `{vc_mention}`   | ช่องเสียงในรูปแบบการกล่าวถึง (#ช่องเสียง) |

#### ตัวแปรค่าที่เพิ่มขึ้นตามลำดับ · [ต้องใช้ Ultimate](/ultimate)

| ตัวแปร    | คำอธิบาย                                                      |
| --------- | ------------------------------------------------------------- |
| `{n}`     | ตัวเลขที่เพิ่มขึ้นตามลำดับอย่างง่าย (1, 2, 3...)              |
| `{nato}`  | ตัวอักษร NATO ที่เพิ่มขึ้นตามลำดับ (Alpha, Bravo, Charlie...) |
| `{roman}` | เลขโรมันที่เพิ่มขึ้นตามลำดับ (I, II, III, IV...)              |

**ตัวเลขที่เพิ่มขึ้นตามลำดับทำงานอย่างไร?**  
เนื่องจาก Discord มีข้อจำกัดใหม่ที่อนุญาตให้เปลี่ยนชื่อช่องเสียงได้เพียง 2 ครั้งทุก 10 นาที ฟีเจอร์นี้จึงทำงานต่างจากที่คุณอาจคาดไว้เล็กน้อย:  
ช่องเสียงจะถูกสร้างตามลำดับ: บอทจะหาช่องเสียงแรกที่ขาดหายไปและวางช่องเสียงใหม่ไว้ในตำแหน่งนั้น

ตัวอย่าง: เรามีช่องเสียง 5 ช่องที่ Astro สร้างตามลำดับ [VC #1, VC#2, VC #3, VC #4 และ VC#5] สมมติว่า VC #3 ถูกลบ สิ่งที่ Astro จะไม่ทำคือเปลี่ยนชื่อทุกช่องให้ถูกต้อง (VC#4 เป็น VC #3 และต่อๆ ไป) แต่ครั้งต่อไปที่สร้างช่อง ช่องนั้นจะไม่ใช่ VC #6 แต่เป็น VC #3 เพื่อเติมช่องว่าง

หากเห็นว่าตัวเลขเริ่มจากเลขผิด คุณกดปุ่ม `ล้างแคช` ในแดชบอร์ดเพื่อรีเซ็ตการนับได้
![ล้างแคช](/guides/clear_cache.png 'ล้างแคช')

คุณยังตั้งค่าได้ว่าควรอัปเดตชื่อช่องเมื่อใด:
![เงื่อนไขการอัปเดตชื่อของ Generator](/guides/generator_name_conditions.png 'เงื่อนไขการอัปเดตชื่อของ Generator')

### ข้อจำกัดของการอัปเดตชื่อ

ชื่อช่องเสียงของ Discord เปลี่ยนได้เพียง 2 ครั้งทุก 10 นาที ซึ่ง Discord เพิ่งนำข้อจำกัดนี้มาใช้ไม่นานนี้ น่าเสียดาย
ด้วยเหตุนี้ ชื่อช่องเสียงอาจไม่ตรงเสมอไปหากมีการเปลี่ยนแปลงบ่อย

## การตั้งค่าพื้นฐาน

ในแดชบอร์ดคุณยังพบตัวเลือกสำหรับเปลี่ยน:

- หมวดหมู่ที่ใช้สร้างช่องเสียงชั่วคราว
- ขีดจำกัดผู้ใช้
- บิตเรต
- ตำแหน่ง: ว่าควรสร้างช่องเสียงชั่วคราวก่อน Generator หลัง Generator หรือไว้ท้ายหมวดหมู่
- หากต้องการเปลี่ยนภูมิภาค คุณเปลี่ยนภูมิภาคของช่อง Generator ใน Discord ได้โดยตรง
- สถานะช่องเสียงเริ่มต้น: ข้อความเล็กๆ ที่แสดงใต้ชื่อช่องเสียง เจ้าของเปลี่ยนได้ตลอดด้วยคำสั่ง `/status`

## การตั้งค่าสิทธิ์

### การสืบทอดสิทธิ์

โดยค่าเริ่มต้น ช่องเสียงชั่วคราวสืบทอดสิทธิ์จาก Generator  
คุณเปลี่ยนพฤติกรรมนี้ได้ในแดชบอร์ด ให้ช่องคัดลอกสิทธิ์จากหมวดหมู่แทน หรือไม่คัดลอกสิทธิ์ใดเลยก็ได้

### บทบาทเป้าหมาย

บทบาทเป้าหมายเป็นหนึ่งในการตั้งค่าที่สำคัญที่สุด เมื่อต้องแก้ไขสิทธิ์ของช่อง เช่น เมื่อช่องถูกล็อกหรือซ่อน Astro จะแก้ไขสิทธิ์ของบทบาทเป้าหมายเพื่อให้ได้สถานะที่ต้องการ  
ตัวอย่างเช่น หากในเซิร์ฟเวอร์ของคุณผู้ใช้ต้องผ่านการยืนยันตัวตนและได้รับบทบาท `ยืนยันแล้ว` คุณคงอยากตั้งบทบาทนั้นเป็นบทบาทเป้าหมาย

### บทบาทผู้ดูแล

หากคุณระบุบทบาทผู้ดูแล บทบาทนั้นจะมีสิทธิ์จัดการช่องเสมอ แม้ช่องจะถูกล็อกหรือซ่อนอยู่

### สถานะเริ่มต้น

คุณเลือกได้ว่าจะให้ช่องเสียงชั่วคราวถูกสร้างแบบล็อกหรือซ่อนโดยค่าเริ่มต้นหรือไม่

## การตั้งค่าคำสั่ง

คุณกำหนดข้อจำกัดบางอย่างให้คำสั่งของผู้ใช้ได้ เช่น ผู้ใช้ใช้คำหยาบในชื่อช่องเสียงได้หรือไม่ (ใช้ได้กับภาษาอังกฤษเท่านั้น) และกำหนดค่าต่ำสุดและสูงสุดที่ผู้ใช้ตั้งได้สำหรับขีดจำกัดผู้ใช้และบิตเรต

## ยูทิลิตี้ที่มีประโยชน์

### บทบาทเจ้าของ

หากระบุ Astro จะมอบบทบาทนี้ให้เจ้าของช่องเสียงชั่วคราว และถอนเมื่อเขาออกจากช่องหรือเมื่อความเป็นเจ้าของถูกโอน

### โหมดคิว

เมื่อเปิดโหมดคิว Astro จะพยายามเติมช่องที่มีอยู่ให้เต็มก่อนสร้างช่องใหม่  
เป็นฟีเจอร์ที่มีประโยชน์เมื่อช่องมีขีดจำกัดผู้ใช้และคุณต้องการให้ทุกช่องเต็มด้วยจำนวนผู้ใช้สูงสุด

### Generator สำรอง

เมื่อหมวดหมู่ของ Generator เต็ม (ถึง 50 ช่อง) ผู้ใช้ที่เข้า Generator จะถูกย้ายไปยัง Generator สำรอง หากมีการตั้งไว้

## ห้องรอ

ห้องรอคือช่องเสียงที่ถูกสร้างขึ้นใกล้กับช่องเสียงชั่วคราว  
ผู้ใช้เข้าห้องรอเพื่อบอกว่ากำลังรอเข้าช่องเสียงชั่วคราว และเจ้าของช่องดึงผู้ใช้จากห้องรอเข้าช่องของตนได้

ในแดชบอร์ดคุณเลือกได้ว่าจะให้ Astro สร้างห้องรอให้ช่องเสียงชั่วคราวแต่ละช่องโดยอัตโนมัติหรือไม่ และตั้งค่าได้ทุกด้าน: ชื่อ (ใช้ตัวแปรได้เช่นกัน) ขีดจำกัดผู้ใช้ บิตเรต ฯลฯ

ผู้ใช้ยังสร้างห้องรอได้ด้วยคำสั่งสแลชหรือปุ่มอินเทอร์เฟซที่เกี่ยวข้อง

## แชทข้อความส่วนตัว

แชทข้อความส่วนตัวคือช่องข้อความที่มองเห็นได้เฉพาะผู้ใช้ภายในช่องเสียงชั่วคราว  
คุณตั้งค่าในแดชบอร์ดได้ว่าจะให้ Astro สร้างแชทข้อความส่วนตัวให้ช่องเสียงชั่วคราวแต่ละช่องหรือไม่ พร้อมการตั้งค่า เช่นเดียวกับห้องรอ

ผู้ใช้ยังสร้างแชทข้อความส่วนตัวได้ด้วยคำสั่งสแลชหรือปุ่มอินเทอร์เฟซที่เกี่ยวข้อง

### ข้อความตอนสร้าง

คุณยังระบุข้อความที่ Astro จะส่งเข้าช่องเสียงชั่วคราวเมื่อสร้างได้  
ข้อความจะถูกส่งในแชทข้อความส่วนตัวหากมี มิฉะนั้นจะส่งในแชทของช่องเสียง (ใช่ มันน่าสับสน แต่ตอนนี้ช่องเสียงก็มีแชทข้อความในตัวเช่นกัน)

คุณเลือกได้ว่าข้อความจะเป็น Embed หรือข้อความธรรมดา

หรือจะให้ Astro ส่ง[อินเทอร์เฟซ](/guides/interface)ในแชทข้อความก็ได้!
