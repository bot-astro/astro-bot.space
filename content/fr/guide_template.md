## Qu'est-ce qu'un modèle

Les modèles regroupent un ensemble de paramètres de salon vocal qui peuvent être appliqués d'un seul coup aux salons vocaux temporaires.

C'est utile par exemple sur les serveurs de jeux où les utilisateurs peuvent jouer à de nombreux jeux différents.  
Avoir un modèle par jeu permet d'adapter le salon vocal à ce jeu, par exemple avec un nom ou une limite d'utilisateurs spécifiques.

## Utiliser les modèles

Les utilisateurs de ton serveur peuvent utiliser les modèles soit avec `/template`, qui propose l'autocomplétion des modèles disponibles, soit avec le bouton d'interface prévu.

## Créer et gérer des modèles

Tu peux créer, gérer et supprimer des modèles dans le [tableau de bord](/guilds).

_N'oublie pas que sans [Ultimate](/ultimate) tu peux avoir au maximum 3 modèles._

## Nom du modèle

Le nom d'un modèle est simplement un nom qui aide les utilisateurs à identifier un modèle.  
**Ce n'est pas** le nom que reçoit le salon vocal temporaire quand le modèle est appliqué.

Quand un utilisateur veut appliquer un modèle à son salon, il voit seulement une liste de modèles où chacun a son propre nom.

## Paramètres du salon vocal

Dans le tableau de bord, tu peux configurer les paramètres qui sont appliqués au salon vocal temporaire quand un modèle est utilisé.

Tu peux choisir :

- le nom du salon vocal, qui prend en charge les [variables](/guides/generator#variables)
- la limite d'utilisateurs
- le débit
- la région

_Aucun de ces paramètres n'est obligatoire, tu n'as donc pas besoin de tous les définir._

## Générateurs activés

Si tu veux restreindre un modèle à certains générateurs précis, tu peux le faire dans le tableau de bord.  
Dans ce cas, le modèle ne sera utilisable par aucun salon vocal temporaire créé par un générateur qui ne figure pas dans la liste `Générateurs activés`.
