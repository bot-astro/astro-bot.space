## 인터페이스란?

인터페이스는 사용자가 간단한 버튼으로 자신의 임시 음성 채널을 빠르게 관리할 수 있게 해주는 메시지예요.  
기본 인터페이스는 다음과 같이 생겼어요:
![기본 인터페이스](/guides/default_interface.png "기본 인터페이스")

## 인터페이스 만들기

대시보드의 인터페이스 섹션에서 새 인터페이스를 만들 수 있어요.  
채널을 물어보면 원하는 채널을 선택하면 돼요.

## 채널 변경 또는 인터페이스 다시 보내기

실수로 인터페이스 메시지를 삭제했거나 채널을 바꾸고 싶다면, 대시보드의 인터페이스 설정에서 할 수 있어요.

## 인터페이스 커스터마이징

대시보드에서 모든 인터페이스를 커스터마이징할 수 있어요. 인터페이스 섹션을 열고 인터페이스를 선택한 다음 관리를 클릭하세요.  
끝나면 변경 사항을 저장하세요. Astro가 바로 메시지를 업데이트해요.

_[Ultimate](/ultimate) 없이는 인터페이스의 버튼을 켜고 끄는 것만 가능하고, 그 외의 모든 것은 Ultimate가 필요해요._

### 메시지 설정

메시지는 세 부분으로 나뉘고 각각 고유한 설정이 있어요:

- `헤더`: 작성자 이름, 작성자 링크, 작성자 이미지
- `본문`: 제목, 제목 링크, 썸네일, 설명, 이미지
- `푸터`: 푸터 텍스트, 푸터 이미지, 메시지 왼쪽 선의 색상, 타임스탬프

모든 설정은 선택 사항이며 텍스트를 비워 두면 표시되지 않아요.  
작성자 이미지와 이미지에는 기본값이 있고 `기본값으로 초기화` 버튼으로 되돌릴 수 있어요.

### 이미지

이미지는 서버의 미디어 저장소에서 선택해요. `이미지 선택`을 클릭해서 열면 다음을 할 수 있어요:

- 새 이미지 업로드
- 이미 업로드한 이미지 미리보기
- 편집 중인 설정에 사용할 이미지 선택
- 더 이상 필요 없는 이미지 삭제

_이미지를 삭제하면 편집 중인 인터페이스의 설정에서도 지워져요. 그 이미지를 사용하는 다른 인터페이스는 바꾸기 전까지 깨진 이미지로 표시돼요._

어떤 인터페이스에서도 사용하지 않는 이미지는 가끔 자동으로 정리돼요.

### Custom emojis

이모지는 메시지 텍스트와 버튼에 사용할 수 있어요. 기본 이모지는 그냥 붙여넣으면 되고, Discord 커스텀 이모지는 코드가 필요해요:

1. Discord에서 이모지 앞에 백슬래시를 붙여서 입력하세요. 예: `\:이름:`
2. 메시지를 보내면 Discord가 `<:이름:id>` (애니메이션 이모지는 `<a:이름:id>`) 같은 이모지 코드를 보내줘요
3. 그 코드를 복사해서 대시보드에 붙여넣으세요

## 버튼

인터페이스는 한 줄에 5개씩 최대 5줄의 버튼을 가질 수 있고, 대시보드에서 격자 형태로 보여줘요.  
버튼을 클릭해서 편집하거나 빈 위치를 클릭해서 새 버튼을 추가하세요.

각 버튼에는 다음 설정이 있어요:

- `버튼`: 이 위치에 표시되는 버튼. 한 인터페이스에서 버튼은 한 번만 사용할 수 있어서 이미 다른 곳에 배치된 버튼은 선택할 수 없어요. 제거하려면 `버튼 없음`을 선택하세요
- `비활성화`: 사용자가 버튼을 볼 수는 있지만 클릭할 수는 없어요
- `이름`: 버튼에 표시되는 텍스트
- `이모지`: 버튼에 표시되는 이모지
- `스타일`: 버튼의 색상

버튼이 표시되려면 이름이나 이모지가 최소 하나는 있어야 해요.
