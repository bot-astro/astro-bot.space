## 생성기란?

생성기는 Astro가 만들고 관리하는 채널이에요.  
사용자가 생성기에 참여하면 Astro가 임시 음성 채널을 만들고 사용자를 그 안으로 이동시켜요.

임시 음성 채널을 만든 사용자를 소유자라고 불러요.
소유자는 Astro 슬래시 명령어나 [인터페이스](/guides/interface)로 채널을 관리할 수 있고, 둘 다 채널 이름, 사용자 제한, 권한 등 모든 것을 바꿀 수 있어요.

소유자가 나갔을 때 채널에 다른 _봇이 아닌_ 사용자가 있다면 소유권이 무작위로 다른 사용자에게 넘어가요.  
소유자가 나갔는데 채널에 더 이상 사용자가 없다면 채널이 삭제돼요.

생성기는 매우 높은 수준으로 커스터마이징할 수 있어요. 이 가이드에서는 서버의 요구에 딱 맞게 설정하는 방법을 알아봐요!

## 생성기 만들기와 관리

Astro는 여러 생성기를 관리할 수 있고 각 생성기는 고유한 설정을 가져요.  
대시보드의 생성기 섹션에서 서버의 모든 생성기를 확인하고, 새로 만들고, 관리하고, 삭제할 수 있어요.

_[Ultimate](/ultimate) 없이는 생성기를 최대 2개까지만 가질 수 있어요._

## 이름 설정

임시 음성 채널은 기본, 잠김, 숨김의 세 가지 상태가 될 수 있어요.  
이 상태는 사용자가 슬래시 명령어나 인터페이스로 전환해요.

각 상태마다 이름을 지정할 수 있어요:
![생성기 이름 설정](/guides/generator_name.png "생성기 이름 설정")

### 변수

`변수`를 사용해서 채널 이름을 동적으로 만들 수 있어요. Astro는 새 이름을 적용할 때 변수를 알맞은 값으로 바꿔요:

#### 음성 채널 소유자 변수

| 변수           | 설명                    |
| ------------ | --------------------- |
| `{nickname}` | 소유자의 닉네임 (없으면 사용자 이름) |
| `{username}` | 소유자의 사용자 이름           |
| `{mention}`  | 소유자의 멘션 (@이름)         |
| `{id}`       | 소유자의 ID               |

#### 음성 채널 소유자 활동 변수 · [Ultimate 필요](/ultimate)

| 변수                      | 설명                           |
| ----------------------- | ---------------------------- |
| `{activity_name}`       | 소유자의 활동 이름 (예: 게임 이름)        |
| `{activity_emoji}`      | 활동을 나타내는 이모지                 |
| `{activity_start_time}` | 소유자가 활동을 시작한 시간              |
| `{activity_end_time}`   | 활동이 끝날 시간 또는 끝난 시간           |
| `{activity_type}`       | 활동의 종류 (플레이 중, 시청 중, 듣는 중 등) |
| `{activity_link}`       | 활동이 트위치 방송일 때 트위치 방송 링크      |

#### 음성 채널 변수

| 변수               | 설명                            |
| ---------------- | ----------------------------- |
| `{vc_name}`      | The name of the vc            |
| `{vc_bitrate}`   | The bitrate of the vc         |
| `{vc_userlimit}` | The user limit of the vc      |
| `{vc_users}`     | The amount of users in the vc |
| `{vc_id}`        | The id of the vc              |
| `{vc_mention}`   | 멘션 형태의 음성 채널 (#음성-채널)         |

#### 증가 값 변수 · [Ultimate 필요](/ultimate)

| 변수        | 설명                                     |
| --------- | -------------------------------------- |
| `{n}`     | 단순한 증가 숫자 (1, 2, 3...)                 |
| `{nato}`  | NATO 알파벳 순서 (Alpha, Bravo, Charlie...) |
| `{roman}` | 로마 숫자 순서 (I, II, III, IV...)           |

**증가하는 숫자는 어떻게 동작하나요?**  
Discord가 새로 도입한 제한 때문에 음성 채널 이름은 10분에 2번만 바꿀 수 있어서, 이 기능은 생각하시는 것과는 조금 다르게 동작해요:  
음성 채널은 순차적으로 생성돼요. 봇이 비어 있는 첫 번째 음성 채널 번호를 찾아 새 음성 채널을 그 자리에 넣어요.

예시: Astro가 순차적으로 만든 음성 채널이 5개 있다고 해요 [VC #1, VC#2, VC #3, VC #4, VC#5]. 이때 VC #3이 삭제되면 Astro는 모든 채널의 이름을 바로잡기 위해 VC#4를 VC #3으로 바꾸는 식으로 이름을 바꾸지 않아요. 대신 다음에 새로 만들어지는 채널은 VC #6이 아니라 VC #3이 되어 빈자리를 채워요.

번호가 잘못된 숫자부터 시작한다면 대시보드의 `캐시 지우기` 버튼을 눌러 카운트를 초기화할 수 있어요
![캐시 지우기](/guides/clear_cache.png "캐시 지우기")

### 이름 업데이트 조건

채널 이름이 언제 업데이트되어야 하는지도 설정할 수 있어요:
![생성기 이름 업데이트 조건](/guides/generator_name_conditions.png "생성기 이름 업데이트 조건")

### 이름 업데이트 제한 사항

Discord 음성 채널의 이름은 10분에 2번만 바꿀 수 있어요. 안타깝게도 Discord가 얼마 전에 도입한 제한이에요. 그래서 변경이 잦으면 음성 채널 이름이 항상 정확하지 않을 수 있어요.
Because of that voice channel names may not be always precise if frequent changes occur.

## 기본 설정

In the dashboard you will also find the options to change:

- 임시 음성 채널이 생성되는 카테고리
- 사용자 제한
- the bitrate
- 위치: 임시 음성 채널을 생성기 바로 앞에, 바로 뒤에, 또는 카테고리 맨 아래에 만들지
- 지역을 바꾸려면 Discord에서 직접 생성기 채널의 지역을 바꾸면 돼요
- 기본 음성 채널 상태: 음성 채널 이름 아래에 표시되는 작은 텍스트로, 소유자가 `/status` 명령어로 언제든 바꿀 수 있어요

## 권한 설정

### 권한 상속

임시 음성 채널은 기본적으로 생성기의 권한을 상속해요.  
대시보드에서 이 동작을 바꿀 수 있어요. 채널이 대신 카테고리의 권한을 복사하게 하거나, 아무 권한도 복사하지 않게 할 수 있어요.

### 대상 역할

대상 역할은 가장 중요한 설정 중 하나예요. 채널이 잠기거나 숨겨질 때처럼 채널 권한을 수정해야 할 때 Astro는 원하는 상태가 되도록 대상 역할의 권한을 수정해요.  
예를 들어 서버에서 사용자가 인증 절차를 마치고 `인증됨` 역할을 받아야 한다면, 그 역할을 대상 역할로 설정하는 것이 좋아요.

### 관리자 역할

관리자 역할을 지정하면 채널이 잠기거나 숨겨져 있어도 항상 채널을 관리하는 데 필요한 권한을 가져요.

### 기본 상태

임시 음성 채널을 기본적으로 잠금 또는 숨김 상태로 생성할지 정할 수 있어요.

## 명령어 설정

사용자 명령어에 몇 가지 제한을 둘 수 있어요. 예를 들어 음성 채널 이름에 비속어를 사용할 수 있는지(영어에서만 작동해요), 그리고 사용자가 사용자 제한과 비트레이트에 설정할 수 있는 최솟값과 최댓값을 정할 수 있어요.

## 유용한 유틸리티

### 소유자 역할

지정하면 Astro가 임시 음성 채널 소유자에게 이 역할을 부여하고, 채널을 떠나거나 소유권이 이전될 때 제거해요.

### 대기열 모드

대기열 모드를 켜면 Astro가 새 채널을 만들기 전에 기존 채널을 먼저 채우려고 해요.  
채널에 사용자 제한이 있고 모든 채널을 최대 인원으로 채우고 싶을 때 유용한 기능이에요.

### 대체 생성기

생성기 카테고리가 가득 차면(채널 50개에 도달하면) 생성기에 참여하는 사용자는 설정된 경우 대체 생성기로 이동돼요.

## 대기실

대기실은 임시 음성 채널 옆에 만들어지는 음성 채널이에요.  
사용자는 대기실에 참여해서 임시 음성 채널에 들어가길 기다리고 있다는 것을 알릴 수 있고, 임시 음성 채널의 소유자는 대기실에 있는 사용자를 자신의 채널로 끌어올 수 있어요.

대시보드에서 Astro가 임시 음성 채널마다 대기실을 자동으로 만들지 선택하고, 이름(여기서도 변수를 사용할 수 있어요), 사용자 제한, 비트레이트 등 모든 요소를 설정할 수 있어요.

사용자도 해당 슬래시 명령어나 인터페이스 버튼으로 대기실을 만들 수 있어요.

## 비공개 텍스트 채팅

반면 비공개 텍스트 채팅은 임시 음성 채널 안에 있는 사용자에게만 보이는 텍스트 채널이에요.  
대시보드에서 Astro가 임시 음성 채널마다 비공개 텍스트 채팅을 만들지와 그 설정을 대기실처럼 설정할 수 있어요.

사용자도 해당 슬래시 명령어나 인터페이스 버튼으로 비공개 텍스트 채팅을 만들 수 있어요.

### 생성 메시지

임시 음성 채널이 만들어질 때 Astro가 채널에 보낼 메시지도 지정할 수 있어요.  
비공개 텍스트 채팅이 있으면 그곳에, 없으면 음성 채널 채팅에 메시지가 전송돼요 (네, 헷갈리지만 음성 채널에도 이제 텍스트 채팅이 내장되어 있어요).

메시지를 임베드로 보낼지 단순한 텍스트 메시지로 보낼지 선택할 수 있어요.

또는 Astro가 텍스트 채팅에 [인터페이스](/guides/interface)를 보내게 할 수도 있어요!
